# massfamily.com

Official website repository for the Mass family office. Live site: https://massfamily.com

## About the Mass family office

Mass Family is a private single family office. It provides stewardship and operations for the Mass family. This site and repository do not solicit clients, investments, or partnerships.

Mass Family Trust, established 2007. Stewardship. Holds and administers family assets across generations.

Mass Family Holdings, LLC, established 2026. Operations. Owns and manages the family's operating interests and real property.

Contact: office@massfamily.com

## Domains

massfamily.com is the primary domain and the only email domain for Mass family entities. massfamilytrust.com and massfamilyholdings.com forward permanently (301) to massfamily.com.

## Files in this repository

index.html holds the entire one page site, self contained, no build step. favicon.svg is the Mass lion mark shown in the browser tab. CNAME tells GitHub Pages the custom domain is massfamily.com. The .nojekyll file tells GitHub Pages to serve the files as is.

## Hosting

Static one page site on GitHub Pages, free. Domain and DNS at GoDaddy. Apex A records point to the four GitHub Pages IPs, www is a CNAME to massfamily.github.io. HTTPS enforced with a certificate issued by GitHub.

## Updating the site

Edit index.html on the main branch (pencil icon) and commit. The live site updates within a minute or two.
