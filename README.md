# massfamily.com

One page static site for the Mass family entities. Hosted free on GitHub Pages. Domain at GoDaddy.

## Files

- index.html - the entire site, self contained
- favicon.svg - browser tab icon
- CNAME - tells GitHub Pages the custom domain is massfamily.com

## Updating the site

Edit index.html on the main branch in GitHub (pencil icon) and commit. The live site updates itself within a minute or two. No hosting bill.

## DNS

Registered at GoDaddy. Apex A records point to the four GitHub Pages IPs, www is a CNAME to the GitHub Pages hostname. Other Mass domains forward 301 to massfamily.com via GoDaddy domain forwarding.
